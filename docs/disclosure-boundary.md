# Disclosure Boundary

This repository is intentionally safe for public portfolio and proposal use.

## Not included

- client name, identity, or identifying business information
- email addresses, phone numbers, physical addresses, social handles, or messaging IDs
- private repository URLs or private commit identifiers
- credentials, secrets, keys, tokens, or webhook values
- production IPs, endpoints, hostnames, or internal infrastructure
- contract IDs, payment details, milestone values, invoices, or marketplace messages
- confidential screenshots, alert exports, or spreadsheets
- client-delivery source code or production configurations
- unverified profitability, accuracy, win-rate, ROI, savings, latency, or performance claims

## Repository relationship

This public repository is a **separate sanitized showcase**. It is not a mirror, fork, shared-history branch, or source-code export of the confidential delivery repository.

The confidential delivery repository remains the engineering source of truth and is not shared in public proposals.
