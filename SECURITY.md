# Security Policy

This repository contains a sanitized public case study, not production trading software.

If you notice accidental disclosure of credentials, private infrastructure, client identity, personal contact information, confidential screenshots, or delivery material, do not redistribute the exposed value. Open a GitHub issue that describes only the category and affected file without repeating sensitive content.

Do not submit real credentials, private endpoints, account data, client data, proprietary strategy source, or production alert payloads to this repository.
